ADR-006: Resolution of Duplicate Schema Draft Date: 2026-08-15 Status: Accepted
Context: Two schema documents existed in Phase A artifacts: database_schema.PDF (the schema formally reviewed and referenced throughout the PRD, ADR-002, ADR-004, and ADR-005) and Schema_Addition.docx, an alternate DDL draft covering the same raw/standardized/derived observation tables under different names and a different design.
Comparison found Schema_Addition.docx is missing several requirements already approved elsewhere in Phase A:
No confidence_tier enum — uses a numeric confidence_score/ reliability_score instead, contradicting ADR-005's mandatory categorical tier classification (Official Measurement, Administrative Record, Survey Estimate, Historical Reconstruction, Academic Estimate, Modeled/Derived, Unknown).
No metrics / metric_series_links tables — observations link directly to dataset_id, making it structurally impossible for one metric to map to different source series across eras without blending (required for GNP→GDP pre/post-1929 continuity and the Agriculture Census-vs-NASS dual track, both explicitly required in the Master Plan and Data Dictionary).
No missing_data_records table — violates PRD FR-7 (missing data must be explicit, never silent/zero).
No revision/versioning columns (observation_status, valid_from, valid_to) — violates PRD FR-9 (revisions must supersede, never overwrite).
No documented immutability enforcement (grant revocation) on the raw layer.
Decision: database_schema.PDF is the sole canonical schema. Schema_Addition.docx is deprecated and archived, not merged. No table, column, or naming convention from it is adopted.
Consequences: ✅ Positive:
Removes ambiguity before Phase C ingestion work begins
No rework needed — canonical schema already satisfies every Phase A requirement; nothing from the alternate draft was structurally superior ❌ Negative:
None identified. (If Schema_Addition.docx was drafted by a specific contributor under a different design assumption, worth a short conversation so future drafts start from the canonical schema instead of diverging.)
